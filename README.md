# Orderly – Digital Menu Application

Orderly is a digital menu and restaurant ordering system designed to modernize the way restaurants manage menus and process customer orders. The application allows customers to access menus through QR codes, place orders directly from their table, and send them instantly to the kitchen system.

The goal of the project was to create a proof-of-concept solution that reduces human errors in order taking, improves communication between restaurant staff and the kitchen, and provides real-time menu management.

---

## Project Overview

Many restaurants still rely on paper menus and manual order-taking, which can lead to miscommunication, delays, and inefficiencies. Orderly digitizes this process by providing a QR-code-based ordering system that connects customers, restaurant staff, and the kitchen in one platform.

The system enables restaurants to manage menu items dynamically, track orders in real time, and maintain better control over inventory and availability.

---

## Features

### Customer Interface
- QR code-based menu access
- Digital menu browsing
- Add items to cart and modify orders
- Submit orders directly to the kitchen
- Table-based session linking

### Kitchen Interface
- Real-time order tracking
- Order status management (New, In Progress, Completed)
- Kitchen workflow monitoring

### Admin Dashboard
- Menu management (items, categories, prices)
- Menu availability control
- Stock and inventory tracking
- Order statistics and analytics

### System Features
- Secure database storage
- Real-time communication between interfaces
- Menu availability updates based on stock levels
